# Fruit Ninja Bot v0.2

این نسخه بر اساس ویدیوی ارسالی 852×480 تنظیم اولیه شده است.

## چیزی که از ویدیو برای تنظیم استفاده شد

- نسبت تصویر بازی حدود 16:9 است.
- ناحیه اصلی بازی تقریباً از y=48 تا y=432 است.
- HUD بالا و دکمه Pause پایین از ناحیه تشخیص کنار گذاشته می‌شوند.
- میوه‌ها عمدتاً اجسام رنگی و متحرک هستند.
- افکت‌های برش نیز اجسام رنگی/متحرک زیادی ایجاد می‌کنند، بنابراین v0.2 فقط به رنگ تکیه نمی‌کند.
- ویدیوی ارسالی نمونه واضح و کافی از «بمب واقعی» برای آموزش classifier نداشت؛ بنابراین نمی‌توان ادعا کرد که این نسخه بمب را با قطعیت تشخیص می‌دهد.

## تغییرات v0.2

- Motion detection
- تشخیص رنگ + حرکت
- safety mask برای اجسام تیره و متحرک
- حذف کاندیداهای مشکوک
- در حالت اجرای واقعی، فقط وقتی دقیقاً یک کاندیدای قابل قبول وجود داشته باشد gesture ارسال می‌شود.
- Dry Run به صورت پیش‌فرض روشن است تا ابتدا بدون لمس واقعی تست شود.

## بدون کامپیوتر هم می‌شود

دو راه وجود دارد:

### راه 1: ساخت روی خود گوشی
یک IDE اندرویدی مثل AIDE Next/Android IDE می‌تواند پروژه Gradle را روی خود دستگاه build کند. پروژه‌های موبایلی از این نوع وجود دارند، ولی سازگاری و پایداری آنها به نسخه گوشی و پروژه بستگی دارد.

### راه 2: GitHub Actions
این پروژه فایل `.github/workflows/build.yml` دارد. می‌توان پروژه را با مرورگر گوشی داخل GitHub گذاشت و GitHub Actions را اجرا کرد؛ APK به صورت Artifact ساخته می‌شود و بعد از گوشی دانلود می‌شود.

این روش برای کسی که کامپیوتر ندارد معمولاً راحت‌تر است، چون کامپایل روی سرور انجام می‌شود.

## مهم

این نسخه هنوز برای بازی واقعی «ضدبمب قطعی» نیست. برای نسخه نهایی باید چندین فریم واقعی از بمب‌های Fruit Ninja داشته باشیم و یک classifier مخصوص `fruit/bomb/powerup/effect` آموزش دهیم. تا قبل از آن، Dry Run را برای تست نگه دار.
